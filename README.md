#PC Builder Basics

An interactive learning game introducing players to computer hardware, PC assembly, and basic troubleshooting.

##Project Overview

PC Builder Basics is an educational game designed to introduce foundational computer hardware concepts through interactive activities, knowledge checks, and practical challenges.

###Learning Objectives

Players will learn to:

    Identify common computer hardware components and their functions.
    Understand basic PC assembly and system setup.
    Recognize the importance of cooling and proper airflow.
    Apply basic hardware safety and troubleshooting concepts.

##Game Structure

###Level 1: PC Assembly

    Three progressive rounds covering 13 hardware and system components.
    Interactive component placement.
    Knowledge checks and a final assessment.

###Level 2: Troubleshooting

    Investigate a simulated computer overheating scenario.
    Identify the problem, select a repair, and verify the result.

*Key Features*

    1. Interactive PC assembly activities.
    2. Point-based scoring and progression.
    3. Hardware learning and review guide.
    4. Knowledge checks and assessments.
    5. Simulated BIOS/UEFI verification.
    6. Troubleshooting challenges.
    7. Sound effects and optional background audio.

*Technology*

##Getting Started

The game currently runs locally in a modern web browser.

*Clone the repository:*

git clone https://github.com/Alycia614/PC-builder.git
cd PC-builder

Open index.html in your browser. No additional installation is currently required.
